# Exact endpoint-optimization companion

Run from the repository root:

    python -X utf8 -B scripts/verify_advances.py
    python -X utf8 -B scripts/verify_advances.py --optimized

Both execute the same 22 groups in a short temporary tree. Optional `--output FILE.json` writes a compact receipt; `--logs DIRECTORY` preserves complete child output. No solver, network, original ZIP or private repository is required. Python 3.12+ and the standard library suffice for this capsule.

| r1, r2, r3, r4, r5 | Endpoint progression, sharp parity, exact PCR radii, component panel and critical-cycle traps |
| r8 and its parent proof dependencies | Complete three-site support cover and exact rational/integer refutations; complete chart positive control |

| r13 | Two further cost-8232 endpoints, augmentation comparisons, complete affine pruning and necessary cycle cuts |

| verify_completion_excess.py | Separate exhaustive small-carrier checks of completion with excess at most one and lifted two-arm cuts |

The absence of standalone r6/r7 directories is intentional: their general chart is proved in the manuscript, while the r7 proof dependencies needed by the stronger r8 result are included there. `verify_local.py` executes the stated local proof obligations without claiming a replay of all historical move trajectories.

`PROVENANCE.json` binds 361 present imported files to source members and archive hashes. Windows path joins are made POSIX where certificate identity requires it. Imported Python assertions are converted to explicit exceptions so optimization cannot silently disable checks. Their source and packaged hashes are both recorded. Exactly three unused legacy report builders are excluded; their source identities and historical packaged digests remain separately labelled in the provenance ledger. Frozen exploratory records retained for negative controls are data, not proof of global infeasibility or numerical discovery programs.

Use the public wrapper: unselected historical entry points may request files outside this curated verification closure. The wrapper is the supported complete replay interface, and every included manuscript finite claim has a corresponding check. General theorem validity depends on the written proofs, not on sample counts.
