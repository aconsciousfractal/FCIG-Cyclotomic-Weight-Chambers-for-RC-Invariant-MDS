# Verification architecture

The manifest profile checks the distribution, attestation, formal inventory, citation map, PDF metadata/actions and payload identities.

Core also regenerates the 30-row capsule with 29 mutations and the single-prime checks, runs repository tests and the extension suite. Temporary copies host exact algebra, full atlas reconstruction and original-seed verification, mixed walls and literal paired paths, retiming checks, all 42 rounding reconstructions, four patches and separate physical and polynomial checks. Extension mutation counts are 18, 15 and 24.

Full adds manifest-only materialization and clean Git-archive verification. The distributed Git history has one root; subsequent ordinary revision commits are supported. The history check examines reachable objects, not only the current working tree.

The PDF rebuild performs two byte-identical Tectonic 0.16.9 runs. Visual review checks the resulting layout.

Separate algorithms provide specific computational independence, not independent human judgment. Finite checks are complete only in their stated domains; all-order proofs remain written arguments.

Version 3 adds 22 groups for endpoints, parity, local PCR radii, the three-site proof, stable completion and fibre, height optimization, cost-8232 sets, regional traces and affine pruning. Independent base-four and small-carrier checks are part of this runner. Both modes execute explicit exception checks; Python optimization is forwarded to all children. Source adaptations and compressed JSON inputs are validated by the package surface gate.

Pytest discovery is restricted to `tests/` by `pytest.ini`. Historical round scripts with repeated basenames are standalone programs; `verify_advances.py` invokes them in separate processes in both requested interpreter modes. This avoids module-name collisions without omitting their certificate and mutation checks.

Version 3.1 adds the balanced-load replay in both modes to core. It checks the literal nonstable selection, core DAG/rank/path, signed rational lift, all closed-walk rows, return coverage, ceilings, exterior circulation and the five PCR deficits. Five semantic mutations change mathematical content and must be rejected. The seven source payload hashes are additionally checked at the package surface. This capsule shares its graph kernel with its source; a second independent graph implementation is not claimed.

Version 3.2 adds the evidence-tree identity quoted by the PDF, checks the companion URI and fixed-family scope, and guards against the concrete workspace-path residue addressed in this revision. The PDF inventory follows the active LaTeX inputs, including technical appendices.
